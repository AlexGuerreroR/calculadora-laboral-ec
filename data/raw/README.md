# Fuentes normativas

Esta carpeta contiene los documentos oficiales que pueden ser almacenados directamente como parte del proyecto.

## Código del Trabajo

La versión del Código del Trabajo utilizada como fuente de consulta se encuentra publicada en el sitio web oficial del Ministerio del Trabajo del Ecuador.

URL:

https://www.trabajo.gob.ec/wp-content/uploads/downloads/2024/01/CODIGO_DEL_TRABAJO.pdf

Fecha de consulta: 17 de octubre de 2026.

Aunque el documento se encuentra alojado en el dominio oficial del Ministerio del Trabajo, el PDF consultado contiene restricciones expresas de reproducción y redistribución.

Por esta razón, el archivo no se almacena dentro de este repositorio público.

Para los procesos de revisión normativa o ingesta local, deberá descargarse directamente desde la URL indicada.
